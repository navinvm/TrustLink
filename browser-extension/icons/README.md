# TrustLink Extension Icons

This folder should contain the extension icons in the following sizes:

- **icon16.png** - 16x16 pixels (toolbar, small displays)
- **icon32.png** - 32x32 pixels (extension management)
- **icon48.png** - 48x48 pixels (extension management, popup)
- **icon128.png** - 128x128 pixels (Chrome Web Store, installation)

## Creating Icons

You can create these icons from the main TrustLink logo or design custom ones.

### Design Guidelines

**Colors:**
- Primary: Purple/Blue gradient (#667eea to #764ba2)
- Accent: White or light colors for contrast

**Symbol:**
- Shield or lock icon (security theme)
- "TL" monogram
- Check mark or verification symbol

### Quick Generation

If you don't have icons yet, you can:

1. **Use an online icon generator:**
   - [favicon.io](https://favicon.io/)
   - [Real Favicon Generator](https://realfavicongenerator.net/)

2. **Create with design tools:**
   - Figma, Adobe Illustrator, or Canva
   - Export in PNG format at required sizes

3. **Use placeholder icons temporarily:**
   - Create simple colored squares with "TL" text
   - Use any image editing tool

### Temporary Placeholder

Until you create custom icons, you can use solid colored squares with text:

```
Background: #667eea (TrustLink purple)
Text: "TL" in white, bold
```

## Notes

- Icons must be PNG format
- Transparent backgrounds recommended
- Keep designs simple and recognizable at small sizes
- Ensure 128x128 icon looks good for store listings
