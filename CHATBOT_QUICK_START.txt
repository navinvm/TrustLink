🔧 TROUBLESHOOTING:

❓ "Model is loading" message?
   → Normal! Wait 10-20 seconds and try again.

❓ Chatbot button not appearing?
   → Check console: Should say "✓ AI Chatbot enabled with Hugging Face"
   → Clear browser cache and reload

❓ Responses too slow?
   → Get free HuggingFace token (see above)
   → Or switch to faster model in .env

❓ Want to switch to OpenAI?
   → Set CHATBOT_PROVIDER=openai in .env
   → Add OPENAI_API_KEY=sk-your-key
   → pip install openai
   → Restart server
