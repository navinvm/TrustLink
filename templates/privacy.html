Privacy & Security

Your privacy and security are our top priorities. Learn how we protect your data and ensure safe, transparent phishing detection.

Our Privacy Guarantees

Anonymous Scanning

URLs from anonymous users are processed in real-time and immediately discarded. We don't track or store your scans without an account.

Minimal Data Collection

We only collect what's necessary: URLs for scan history (registered users), account credentials, and basic analytics for service improvement.

Strong Encryption

All passwords are encrypted with bcrypt hashing. API keys are secured with industry-standard encryption. HTTPS enforced on all connections.

No Third-Party Sharing

Your data is never sold, shared, or transferred to third parties for marketing or any other purposes. Your privacy is not for sale.

Limited Retention

Scan results are cached for 24 hours for performance. Scan history is retained only for registered users and deleted upon account deletion.

Right to Delete

You have full control over your data. Delete your account anytime, and all associated data will be permanently removed from our systems.

Security Measures

Application Security

  • CSRF Protection: All forms protected with CSRF tokens to prevent cross-site request forgery attacks.
  • Input Validation: All user inputs are validated and sanitized to prevent SQL injection, XSS, and other injection attacks.
  • Rate Limiting: API calls limited to 1000 requests per hour per user to prevent abuse and DDoS attacks.
  • Secure Sessions: Session cookies are HTTP-only, secure, and use SameSite protection. Sessions expire after inactivity.
  • Password Security: Bcrypt hashing with salt for all passwords. Minimum 8 characters, complexity requirements enforced.
  • API Key Security: API keys are hashed using SHA-256. Keys can be revoked instantly by users.

Infrastructure Security

  • HTTPS Enforcement: All connections use TLS/SSL encryption. HTTP traffic is redirected to HTTPS.
  • Database Encryption: Sensitive data encrypted at rest. Database files protected with file system permissions.
  • Connection Pooling: Secure database connections managed through connection pooling to prevent connection exhaustion.
  • Security Headers: X-Frame-Options, X-Content-Type-Options, and Content Security Policy headers enabled.
  • Error Handling: Detailed errors hidden from users. Generic error messages prevent information leakage.

Monitoring & Response

  • Security Logging: Authentication failures, suspicious activities, and rate limit violations are logged.
  • Health Checks: Automated monitoring of system health, database connectivity, and cache availability.
  • Anomaly Detection: Unusual patterns in scan requests or authentication attempts trigger alerts.
  • Incident Response: Security incidents are investigated and addressed within 24 hours.

How We Use Your Data

URL Scanning

URLs you submit are analyzed by our ML model to detect phishing threats. For registered users, scan results are saved to your history for future reference.

Service Improvement

Aggregated, anonymized analytics help us improve detection accuracy, optimize performance, and identify new threat patterns.

ML Model Training

Our ML model is trained on publicly available phishing datasets. Individual URLs scanned are never linked to specific users in training data.

Communication

Email addresses are used for account verification, password resets, and optional security notifications. We never send marketing emails.

Abuse Prevention

IP addresses and rate limiting data are used temporarily to prevent spam, abuse, and automated attacks. This data is not stored long-term.

Third-Party Services

TrustLink integrates with the following third-party services for enhanced phishing detection:

Google Safe Browsing API (Optional)

When enabled, URLs may be sent to Google Safe Browsing for verification. Google's privacy policy applies to this data. This service can be disabled in settings.

VirusTotal API (Optional)

When enabled, URLs may be checked against VirusTotal's database. VirusTotal's privacy policy applies. This service can be disabled in settings.

Redis Cache (Optional)

If Redis is configured, scan results may be cached in Redis for performance. Data is encrypted and expires after 24 hours.

Note: External API calls are only made for registered users with consent. Anonymous scans use only our internal ML model unless explicitly opted in.
