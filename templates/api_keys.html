API Usage

Use your API key to make requests to the TrustLink API:

Single URL Scan

curl -X POST https://YOUR_DOMAIN/api/v1/scan \
  -H "Content-Type: application/json" \
  -H "X-API-Key: YOUR_API_KEY" \
  -d '{"url": "http://example.com"}'

Batch Scan (up to 100 URLs)

curl -X POST https://YOUR_DOMAIN/api/v1/batch-scan \
  -H "Content-Type: application/json" \
  -H "X-API-Key: YOUR_API_KEY" \
  -d '{"urls": ["http://site1.com", "http://site2.com"]}'

Get Statistics

curl https://YOUR_DOMAIN/api/v1/stats \
  -H "X-API-Key: YOUR_API_KEY"
Security Note: Replace YOUR_DOMAIN with your actual TrustLink server domain. Never share your API keys publicly.
